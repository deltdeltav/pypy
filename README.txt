🚀 БЫСТРЫЙ СТАРТ

Вариант А: Просто играть (рекомендуется)
1. Открой папку "🎮 ИГРАТЬ СЕЙЧАС"
2. Запусти "DeltaCorePro.exe"
3. Играй! Прогресс сохраняется автоматически.

Вариант Б: Запуск из исходников (для моддеров)
1. Установи Python 3.10+ с https://python.org
   ✅ При установке отметь галочку "Add Python to PATH"
2. Открой папку "💻 ДЛЯ РАЗРАБОТЧИКОВ"
3. Запусти файл "run_game.bat" (двойной клик)
   ИЛИ вручную в консоли:
   > python -m pip install pygame --user
   > python main.py

🎮 УПРАВЛЕНИЕ

[ЛКМ]  - Построить башню / Выбрать юнита
[ПКМ]  - Двигать камеру (перетаскивание)
[P]    - Открыть меню (Прокачка / Магазин / Донат)
[1-6]  - Быстрый выбор юнита
[ESC]  - Закрыть меню
[R]    - Рестарт после Game Over

🔧 МОДДИНГ

Хочешь изменить игру? Правь файлы в папке исходников:

• Баланс юнитов/врагов → settings.py
• Цвета и визуал → settings.py (класс Colors)
• Поведение снарядов → entities.py (класс Projectile)
• Генерация карт → map_gen.py

После изменений просто запусти run_game.bat — изменения применятся сразу!
